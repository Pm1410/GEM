    1. Implement src/gem_api/audit/chain.py:
       - GENESIS_HASH = "0" * 64
       - AuditPayload dataclass / Pydantic model:
         tender_id: str
         tender_version: str
         rule_set_version: str
         bidder_id: str
         requirement_results: list[dict[str, Any]]
         evidence_hashes: list[str]
         compliance_score: float
         risk_level: str
         advisory_text_hash: str
         officer_action: Optional[str] = None
         officer_justification: Optional[str] = None
         timestamp: str
       - compute_payload_hash(prev_hash: str, payload: dict[str, Any]) -> str:
         Canonical JSON serialization: json.dumps(payload, sort_keys=True, separators=(',', ':'))
         SHA-256 digest of (prev_hash + canonical_json).
       - AuditChainVerificationResult dataclass:
         is_valid: bool
         total_records: int
         broken_index: Optional[int] = None
         expected_hash: Optional[str] = None
         computed_hash: Optional[str] = None
         message: str = "Audit trail is intact and verified."
       - verify_audit_chain(records: list[dict[str, Any]]) -> AuditChainVerificationResult:
         Walks through list of records in chronological order.
         Verifies each record's prev_hash matches prior record's record_hash.
         Recomputes hash from payload and verifies record_hash matches.
         If mismatch, returns immediately with broken record details.
    2. Write tests/unit/test_audit_chain.py:
       - Test genesis hash and valid sequential chain creation.
       - Test verification of clean multi-record chain.
       - Test tamper detection: payload modification is flagged.
       - Test tamper detection: prev_hash modification is flagged.
       - Test tamper detection: record reordering or deletion is flagged.
  </action>

    1. Implement src/gem_api/security/encryption.py:
       - EncryptedBlob dataclass:
         ciphertext: bytes
         nonce: bytes
         sha256_digest: str
       - encrypt_document(data: bytes, key: bytes) -> EncryptedBlob:
         Uses AES-256-GCM via cryptography.hazmat.primitives.ciphers.aead.AESGCM.
         Computes sha256_digest of plaintext.
         Generates 12-byte random nonce, encrypts data with nonce.
       - decrypt_document(blob: EncryptedBlob, key: bytes) -> bytes:
         Decrypts using AESGCM, verifies decrypted plaintext against sha256_digest.
         Raises ValueError on corruption or key mismatch.
    2. Implement src/gem_api/security/retention.py:
       - RetentionPolicy dataclass:
         retention_days: int = 1825 (5 years default per government records rules)
         created_at: datetime
         expires_at: datetime
         is_expired: bool
         purge_status: str ("RETAINED", "PURGED", "LOCKED")
       - compute_retention_policy(created_at: datetime, retention_days: int = 1825) -> RetentionPolicy
       - is_retention_expired(policy: RetentionPolicy, as_of: Optional[datetime] = None) -> bool
    3. Export in src/gem_api/security/__init__.py.
    4. Write tests/unit/test_security.py:
       - Test encryption and decryption round-trip.
       - Test decryption failure with incorrect key.
       - Test decryption failure if ciphertext is tampered.
