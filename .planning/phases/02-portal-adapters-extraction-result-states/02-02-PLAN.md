       - validate_file_upload(file_bytes: bytes, filename: str, content_type: str, max_size_mb: int = 10) -> bool
         Rejects file size > 10MB, validates content_type in ['application/pdf', 'image/png', 'image/jpeg'], checks magic bytes (%PDF, PNG header, JPEG header).

       - ExtractedDocument dataclass (pages: list[PageData], total_pages: int, metadata: dict)

       - extract_document(file_bytes: bytes, content_type: str) -> ExtractedDocument:
         Using PyMuPDF (fitz) to extract text per page.
         If page text density is < 50 characters and PyMuPDF renders pixmap, attempt OCR via pytesseract if available (graceful fallback if pytesseract system binary not installed).
    3. Export sanitizer and extractor in __init__.py.
