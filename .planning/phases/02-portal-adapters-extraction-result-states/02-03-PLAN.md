    1. Implement src/gem_api/rules/result_aggregator.py:
       - aggregate_requirement_states(rule_results: list[RuleResult]) -> AggregatedEvaluation
         Calculates overall state using strict priority:
         1. If ANY check is FAIL -> overall state is FAIL (explicit violation).
         2. Else if ANY check is REVIEW -> overall state is REVIEW (deficiency/ambiguity needs human eyes).
         3. Else if ANY check is UNVERIFIABLE -> overall state is UNVERIFIABLE (external service down).
         4. Else -> PASS (all checks satisfied with attached evidence).
       - AggregatedEvaluation includes counts: {pass_count, fail_count, review_count, unverifiable_count}, overall_state, and findings list.
    2. Write tests/unit/test_result_states.py:
       - Test PASS state: all checks pass with verified evidence.
       - Test FAIL state: checksum failure, expired certificate, entity mismatch, or debarred entity.
       - Test REVIEW state: missing required field, ungrounded extraction, unreadable document.
       - Test UNVERIFIABLE state: portal timeout, 500 error, network unreachable.
       - Test Priority Hierarchy: FAIL overrides REVIEW and UNVERIFIABLE; REVIEW overrides UNVERIFIABLE and PASS; UNVERIFIABLE overrides PASS.
       - Test Zero False-PASS property: verify that no permutation containing a failed check or unreachable portal can ever produce PASS.
  </action>
