  <action>
    1. Implement gstin.py:
       - Validate length == 15.
       - Validate state code (chars 1-2) against Census 2011 codes ("01" to "37").
       - Validate PAN structure (chars 3-12).
       - Validate entity number (char 13 alphanumeric 1-9, A-Z).
       - Validate default 'Z' (char 14).
       - Calculate Mod-36 checksum according to official GSTN algorithm using alphabet "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ" and compare with char 15.
       - Return ValidatorResult(is_valid: bool, code: str, reason: Optional[str]).
    2. Implement pan.py:
       - Validate regex ^[A-Z]{5}[0-9]{4}[A-Z]$.
       - Validate position 4 entity type in {'P', 'C', 'H', 'F', 'A', 'T', 'B', 'L', 'J', 'G'}.
    3. Implement udyam.py:
       - Validate regex ^UDYAM-[A-Z]{2}-[0-9]{2}-[0-9]{7}$.
    4. Implement date_checks.py:
       - check_valid_as_of(cert_expiry: date, bid_opening_date: date) -> ValidatorResult.
       - Must ensure cert_expiry >= bid_opening_date. Never compares to current/system date.
    5. Implement cross_checks.py:
       - check_gstin_pan_match(gstin: str, pan: str) -> ValidatorResult. Characters 3-12 of GSTIN must equal PAN.
    6. Write unit tests in tests/unit/test_validators.py covering positive, negative, and edge cases for all 5 checks.
  </action>
  <verify>pytest tests/unit/test_validators.py -v</verify>

    - test_date verifies certificate valid on bid_opening_date passes even if expired relative to today
