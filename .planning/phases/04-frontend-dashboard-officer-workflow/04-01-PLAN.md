    1. Implement src/gem_api/advisory/generator.py:
       - AdvisoryReport dataclass:
         summary_text: str
         statutory_findings: list[str]
         technical_findings: list[str]
         cited_requirement_ids: list[str]
         recommended_action: str ("APPROVE" | "REJECT" | "REQUEST_CLARIFICATION")
         advisory_hash: str
         disclaimer: str
       - generate_advisory(
             report: TenderEvaluationReport,
             score: ComplianceScore,
             risk: RiskProfile,
         ) -> AdvisoryReport:
         - Deterministic template construction.
         - Cites all non-PASS requirement IDs (REQ-XX).
         - Recommends:
           - REJECT if risk is CRITICAL or any mandatory requirement has failed statutory checks.
           - REQUEST_CLARIFICATION if state is REVIEW or UNVERIFIABLE.
           - APPROVE if state is PASS and risk is LOW.
         - Generates SHA-256 hash of advisory summary.
    2. Write tests/unit/test_advisory.py testing:
       - Compliant bidder produces APPROVE advisory.
       - Debarred/failed bidder produces REJECT advisory with cited REQ-XX.
       - Missing evidence/timeout produces REQUEST_CLARIFICATION with cited REQ-XX.
       - Disclaimer is present in all outputs.
  </action>
  <verify>pytest tests/unit/test_advisory.py -v</verify>
  <acceptance_criteria>
    - test_advisory.py passes with 100% success
    - Every advisory contains REQ-XX citations and legal disclaimer
  </acceptance_criteria>
  <done>Advisory generator and unit tests implemented</done>
